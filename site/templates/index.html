The Sensory Triad

Three sensing modalities, named from evolutionary biology:

👂 fEAR — HOW WE HEAR Evidence intake, OSINT collection, signal detection. Event-driven, discrete, receive-only. Long range. Adversary actions as fuel.
👃 preSCENT — HOW WE SMELL Pattern recognition, network mapping, graph analysis. State-driven, gradients, bidirectional. Close range. Ambient presence broadcast.
🦶 STRIDe — HOW WE MOVE Filing, publication, strategic action. Continuous, proprioceptive. Self range. R⇄I loop, deployment cadence.

The Dispersal Pattern

Any domain that produces typed, citable claims with verifiable sources can produce a .primals.eco site. The substrate is domain-agnostic — each site owns its registries and edge grammar; litho-core provides the common plumbing.

detroit.primals.eco is the reference implementation. This site documents the methodology. Future case studies inherit the same pattern.
